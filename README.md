# 500-Midterm-Report

## Medical Imaging & Computer Vision - Group 4

### Dataset

We will use PneumoniaMNIST+, part of the MedMNIST collection. We will
use the 224 × 224 pixel version of the dataset.

PneumoniaMNIST contains pediatric chest X-ray images labelled as either
normal or pneumonia. The dataset provides predefined training,
validation, and test sets.

Source: MedMNIST

### Problem

Our project will investigate whether computer vision models can classify
pediatric chest X-ray images as either pneumonia or normal.

The input will be a chest X-ray image, and the predicted output will be
one of two classes: pneumonia or normal.

This problem is relevant to the automated analysis of pediatric chest
radiographs and the potential use of AI to support medical image
interpretation.

### Task Type

Binary image classification

### Research Question

How accurately can computer vision models classify pediatric chest
X-ray images as pneumonia or normal using the PneumoniaMNIST+ dataset?
